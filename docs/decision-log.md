## 미결 사항

| 항목 | 필요한 것 |
|---|---|
| TPS2660 RTN 연결 (R22) | TPS2660 데이터시트 — RTN을 GND에 묶으면 역극성 보호가 꺼짐 |
| 임시 핀 번호 IC | LMR36006, PCAP04, DAC8760, TPS26611 데이터시트 |
| 출력 사양 | 전압/전류 선택 유지 또는 전류 전용 → DAC 품번 확정 (#10) |
| M Connect 품번 | 커넥터 장착 나사, 리드 꼬임 대책 (뒤 너트 고정형 여부) |
| HTX99R 커넥터 | 재질·내열(120 °C)·내유성, 몰드 핀 누설, 두 번째 홈(Ø8.1) 용도. **HTX99R 센서 프로브 STEP**(핀 규격) 요청. 바디 튜브 Ø14 설치 호환성(볼밸브 등), 커넥터 체결 토크 |
| **습도 센서 구동** | MK33은 **DC 바이어스 없는 교류(1–100 kHz)** 로 측정해야 함 → PCAP04 플로팅·보상 모드로 만족하는지 확인 (PCAP04 데이터시트) — 회로 확정 전 필수. [스터디](reference/ist-mk33-study.md) |
| 습도 센서 | 공급 중인 MK 센서 품번 확인 (mini = 150138), PTFE 절연 + 글롭탑 사양 문의, 오일 최고 온도(HYT 271안 판단), HTX99R 4핀일 때 Pt1000 2선식 허용 여부 |
| 온도 센서 | 캐리어 접합 방식(용접/납땜 → 리드선 사양 또는 SMD 0805), F0.1/F0.15 견적, ADS1220 2선식 회로 변경 |
| **필터 캡 나사 규격** | 필터 도면은 **M10×1.0**, #15에서 커넥터 위 나사는 M10×0.75로 기록됨 → 필터 도면 기준(M10×1.0)으로 반영. **HTX99R 위·아래 나사 피치 실측 확인** 필요 (아래 = 바디 암나사 M10×0.75 유지) |
| **압력 격벽 (Rev F)** | 피드스루가 없어 HTX99R 몰드 핀·O링·포팅이 오일 압력을 직접 받음 → HTX99R 정격 압력·온도(120 °C), 핀 누설, 포팅재(내유·내열 에폭시) 확인, 내압 75 bar·누설 시험 |
| **필터 재질** | 390000-001100은 SUS304, 나머지 접액부는 316L → 오일 용도는 304로 충분한지, 316L 통일 여부 |
| **센서 하네스 커넥터 온도** | JST SH/GH 정격 **−25 ~ +85 °C** (JST 카탈로그, 확인 필요). 오일 120 °C·주위 −40 °C에서 J3(PCB 앞 끝) 온도 시험 필요. 넘으면 −40 ~ +105 °C급 1.0 mm 커넥터(예: Molex Pico-Clasp 계열, 정격 확인)로 교체 — 같은 4핀 배정이라 풋프린트만 변경 |
| 기타 | IST MK 센서 도면, 압력 등급(50 / 200 bar), EE364 레지스터 호환 모드 여부 |
