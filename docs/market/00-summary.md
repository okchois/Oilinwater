## 2. 제품 포지셔닝 (제안)

**"교정 성적서가 포함된 ±0.02 aw급, aw+ppm, RS-485 Modbus, 소형 일체형 — 국산, $500 전후"**

| 사양 | 목표 | 근거 |
|---|---|---|
| 측정 | aw, %RS, T, ppm(광유·에스테르·유압유 계수 내장, 사용자 계수) | 에스테르 확산, 중국 제품 대비 ppm 신뢰성 |
| 정확도 | ±0.02 aw (0–0.9), ±0.03 (0.9–1) | EE364·AFO·MMT162와 같은 급 |
| 압력/온도 | **50 bar 기본, 200 bar 고압형** / −40~120 °C | EE364(20 bar/80 °C)보다 높게, 유압 시장 요건 충족 |
| 출력 | RS-485 Modbus RTU 기본, 옵션으로 4–20 mA 2ch | 결정 사항 |
| 커넥터/연결 | M Connect(원형 M 시리즈), G½ ISO 228 | 결정 사항 |
| 센서 | IST AG MK 계열 | 공급 중 |
| 펌웨어 | RS-485 부트로더 현장 업데이트, 진단 레지스터(NE107) | 설계 완료, 경쟁 제품 대비 강점 |
| 호환 | **EE364 교체 호환 옵션**(핀맵·레지스터 맵) | 기존 EE364 설치 현장에서 그대로 교체 |
| 알람 프리셋 | 60/80 %RS 기본, 용도별 프리셋 | HYDAC·Rivertrace 관행 |

## 3. 파생 모델 로드맵 (제안)

1. **v1 (RS-485 기본형):** 유압·윤활, 변압기 OEM(TMS 업체)
2. **v1.1 (4–20 mA 2ch + RS-485, 8핀):** EE364 교체 수요
3. **v2 (IO-Link):** 유압 파워유닛, 공작기계. ±0.02 aw에 ppm까지 주는 IO-Link 제품은 아직 없음
4. **v2 (CAN/J1939):** 건설기계 OEM
5. **장기:** 복합 센서(유전율, 전도도), 무선형, 변압기용 종이 절연 수분 추정 기능

## 4. 국내 진입 경로 (제안)

1. **변압기:** 한전 중소벤처 협력 R&D(최대 20억 원, 기업 부담 15% 이상)나 구매조건부 과제로 국산화 실적을 확보합니다. 이후 변압기 3사와 TMS 업체(피닉스테크 등)에 OEM으로 공급합니다.
2. **유압·윤활:** 윤활관리 업체(솔지, 비투솔루션)와 필터·정제기 업체를 채널로 씁니다.
3. **인증:** KC 적합등록을 기본으로 하고, 선박은 KR, 방폭 구역은 KCs를 추가합니다.
4. **공공 판로:** 출시 후 NEP/EPC 인증과 조달청 혁신제품 지정을 추진합니다.

## 5. 리스크

- **IST AG 자체 모듈:** IST AG도 오일 프로브 모듈을 팔고 있어, 같은 센서를 쓰는 경쟁사가 나올 수 있습니다. → 차별화는 오일 DB, 교정 추적성, 펌웨어·진단 기능에서 만들어야 합니다.
- **중국 저가 제품의 가격 압박:** → 교정 성적서(KOLAS 소급)와 국내 기술지원으로 대응합니다.
- **한전 조달 구조:** 센서 단품을 직접 납품할 수 있는지 불확실합니다. → OEM 경로를 병행합니다.

## 6. 확인이 필요한 항목

- 경쟁 제품의 실제 가격: 국내 대리점 견적으로 확인
- EE364 핀맵과 Modbus 레지스터 맵: 원문 Quick Guide와 AN0103으로 확인
- IEC 60422 한계값: 원문 확인
- 한전 예방진단시스템에 수분 센서가 포함되는지, 센서 단품 조달 경로: 한전·TMS 업체에 문의
