| 항목 | EE364 |

| ppm 범위 | 0–100 000 ppm (오일 의존), ppm 출력은 0–100 °C에서 유효 |

### 주문 옵션

- 공정 연결: G½ ISO(PA1) / ½" NPT(PA2)
- 센서 보호: LeadsShield(C2, 리드 보호), ChemShield(C4, 오일 열화·에스테르유 대응 코팅), 둘 다(C6)
- 필터: 유속 < 1 m/s용(F13) / > 1 m/s용(F18)
- 출력 1·2 측정값과 스케일: 기본값 OUT1 aw 0–1, OUT2 T −20~80 °C
- 단위: SI / US
- ppm 환산 오일 파라미터: 광유 변압기유 기본. 고객 오일은 **오일 2 L를 보내 E+E가 파라미터를 측정**(Oil-ppmcal)하거나, 포화곡선으로 계산(Oil-calc)
- 액세서리: 8핀 M12 소켓, 차폐 케이블(1.5/5/10 m), 샘플링 셀(PN40, DN25)

## 4. Modbus (Quick Guide)

| 항목 | 값 |
|---|---|
| 공장 설정 | **9600 bps, 8E1, 주소 243** |
| 선택 가능 | 9600 / 19200 / 38400 / 57600 / 76800 bps, 패리티 N/O/E, 정지비트 1/2, 주소 1–247 |
| 통신 설정 레지스터 | 주소 0x00 (Modbus 주소), 0x01 (통신 설정) — FC06 쓰기 |
| 정보 | 시리얼 번호 ASCII 레지스터 1–8, 펌웨어 버전 레지스터 9, 센서 이름 레지스터 10 |

**측정값 (FLOAT32, FC03/FC04 읽기)**

| 측정값 | 레지스터 번호 (1부터) | 주소 (0부터) |
|---|---|---|
| 온도 T | 26 | 0x19 |
| 수분 활동도 aw | 52 | 0x33 |
| 수분 함량 x [ppm] | 54 | 0x35 |
| 오일 파라미터 A, B, C, D, E | 224, 226, 228, 230, 232 | 0xDF, 0xE1, 0xE3, 0xE5, 0xE7 |

- 오일 파라미터 쓰기(FC16):
  - 구형 방식: A, B만 주소 0x64, 0x66에 씁니다. 이때 C, D, E는 0으로 설정됩니다.
  - 펌웨어 2.0.22 이상: A–E를 0xDF부터 씁니다.
- **FLOAT32 워드 순서는 하위 워드 먼저(CDAB)입니다.** 문서 예시로 확인했습니다.
  - A = −100 → `00 00 C2 C8`
  - B = 7.3705 → `DB 23 40 EB`
- ppm 환산은 5개 파라미터 모델(A–E)입니다. 식 자체는 공개되지 않았습니다(AN0103 확인 필요).

## 5. 우리 설계에 주는 시사점

| 항목 | 반영 |
|---|---|
| 핀맵 | 우리 8핀 안(2: B, 3: A, 4: OUT1, 5: OUT2, 6: GND, 8: V+)이 **EE364와 일치함을 원문으로 확인**. 1, 7번은 EE364에서 미사용이므로 7번 AGND 제안과 충돌하지 않음 |
| 전원 | EE364는 10–28 V. 우리 안은 15–30 V(전압 출력 0–10 V와 전류 출력 부하 때문). 교체 호환을 위해 **최소 전압을 12 V 수준으로 낮출 수 있는지** 검토 (저전압 시 부하 저항 제한) |
| 사양 우위 | 압력 20 → 50/200 bar, 오일 100 → 120 °C, IP65 → IP67, 출력 전류 → 전압/전류 선택, RS-485 펌웨어 업데이트 |
| 정확도 | EE364와 같은 수준(±0.02/±0.03 aw, T ±0.2 °C)이 최소 목표 |
| 교체 호환 모드 | EE364 레지스터(0x19, 0x33, 0x35, 0xDF~), **CDAB 워드 순서**, 공장값 9600 8E1 주소 243을 재현하는 모드. 단, EE364는 주소 0x00이 "Modbus 주소" 레지스터라서, 우리 앱의 0x0000(모드 ID "AP")과 충돌함 → 호환 모드에서는 모드 ID를 다른 주소(예: 0xFF00)로 옮겨야 함. 부트로더·업데이트 도구도 함께 수정 필요 |
| 센서 보호 | ChemShield/LeadsShield에 해당하는 소자 보호 코팅을 IST AG에 문의 (에스테르유·해수 오염 대응) |
| 필터 | 유속별 필터캡 2종(< 1 m/s, > 1 m/s) → 우리 교체형 보호캡으로 대응 |
| 서비스 | 오일 파라미터 측정 서비스(오일 2 L 접수)는 우리도 교정실에서 제공 가능한 사업 요소 |
| 설정 도구 | PC 설정 SW + M 커넥터↔USB(RS-485) 어댑터 → 우리 `fwupdate.py`를 설정·업데이트 통합 도구로 확장 |
