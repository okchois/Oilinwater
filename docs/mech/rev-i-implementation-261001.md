# HMT500 기구 Rev I 반영 기록 (2026-10-01)

기구 검토 지적을 생성기에 반영했다. 설치 외형(전장 140 mm, 몸통 Ø30, 노출 Ø12×34), 회로 결정 #36–39는 유지한다. 이 패키지는 설계 검토·가공성 협의용이며 압력·온도 정격 또는 주문 승인을 뜻하지 않는다.

## 바뀐 것

| 항목 | Rev I 변경 | 확인 결과와 한계 |
|---|---|---|
| 센서 캐리어 | 기존 mini 5 mm 형상 대신 MK33-W 300 pF Au/Cu 10.8×3.81×0.8 mm. 캐리어 길이 6.8→13.5 mm | 두 소자와 간격에 필요한 13.3 mm 수용, 보호캡 교차 0. 실제 리드 접합·절연·품번 확인 필요 |
| M3 몰딩 구멍 | 입구 r10→11.8 mm, 원주 90°/270°. 축에서 안쪽으로 **20° 경사**, 입구 M3 탭 깊이 4 mm, Ø2.5 관통 | Ø20 M12 어깨에 Ø2.5 경사 공구 여유 0.625 mm. Ø22 내부까지 개방. 곧게 뚫으면 O링 홈을 침범하므로 경사 유지 필수 |

| 홀더 창 | 하단 z0.98 / 상단 z4.28, 높이 3.3 mm | 최대 두께 PCB 위로 플러그 통과 공간 확보 |

| 검사 도구 | 공구 접근·센서 길이·PCB 최대 두께·O링 홈 검사 추가 | 31개 검사, NG 0 / WARN 1(몰딩 유동). 형상 검사 실패 시 비정상 종료 |

M3 구멍은 엔드캡의 뒤 끝면(x77), r11.8에서 안쪽으로 갈수록 중심축에 가까워지는 방향이다. 두 구멍 모두 반경 평면 안에서 20°이다. 외부 공구는 같은 축의 연장선을 따라 바깥으로 벌어진다. M3×3 마감 나사는 끝면과 간섭하지 않도록 매립하고 실런트를 사용한다. 실제 노즐과 나사 공구 접근, 경사 탭 가공성은 가공업체에서 확인한다.

## 남은 위험 / 주문 전 확인

- 실제 M12 품번: 어깨 Ø20 이하, 안쪽 나사부 ≤6 mm가 현재 모델 조건. 단자·납땜·수축튜브가 PCB 뒤 2 mm 공간을 침범하지 않는지 실물 또는 제조사 STEP으로 확인 필요.
- MK33-W 300 pF 세부 품번과 캐리어 접합 방식 확인 필요. Au/Cu 외형을 적용했으며 SIL 등 다른 옵션을 임의 대체하면 안 된다.
- 에폭시 종류·점도·경화 수축·내유·접착력·온도, HTX99R 몰드 핀 누설·압력 정격 확인 필요. Ø7×12.5 통로의 총체적은 약 0.481 cm³이며 와이어 체적을 빼기 전이다.
- 50 bar/시험 75 bar는 기존 문서의 제안값이다. 제품 정격·시험 조건 확정 전 승인된 압력 성능으로 표기하지 않는다.
- 전자부/JST/수지 최고 온도와 접액부 재질(시제품 SUS304, 원 도면 SUS316L)을 확정해야 한다. JST SH/GH 카탈로그 범위는 −25~85°C이며 120°C 오일에서 PCB 온도가 충분히 낮은지는 시험 필요.
- 몰딩 유동·기포, W-2 하네스 접힘/눌림, 공구 T-001 명목 최소 간격 0.04 mm는 실물 조립 확인 필요. 자동 검사 OK가 제조 공차·배선 변형·열/압력 시험을 대체하지 않는다.
- 조립 시방서의 절연시험 전압은 확인 필요로 바꿨다. 샤시 연결 보호소자가 있는 상태에서 500 V DC를 무조건 인가하도록 하지 않는다.

## 근거

- [IST MK33-W 데이터시트 DHMK33-W_E2.4.0](https://www.ist-ag.com/sites/default/files/downloads/DHMK33-W_E.pdf): 300 pF Au/Cu 소자 외형. 실제 공급 품번 확인 필요.
- [JLCPCB PCB capabilities](https://jlcpcb.com/capabilities/pcb-capabilities/): 1 mm 이상 완성 기판 두께 공차 ±10%.
- [JST SH](https://www.jst-mfg.com/product/pdf/eng/eSH.pdf), [JST GH](https://www.jst-mfg.com/product/pdf/eng/eGH.pdf): 온도 범위.

제조사 데이터시트 PDF는 저장소에 넣지 않았다. 검증 로그와 결과는 본 문서의 검증 기록 및 `hardware/mech/out/assembly_sim/report.json`에 따른다.

## 검증 기록

- 환경: macOS, KiCad CLI 10.0.6, CadQuery 가상환경. AGENTS §5의 회로 생성 → 넷리스트 → PDF → 부품표 → PCB 배치 → JLC BOM/CPL → 전체 unittest 순서 완료. **33 tests OK, 생략 0**.
- 넷리스트 81/81, 오류 0. 재생성한 placement.json의 110개 부품 위치·면·회전·패드·높이·메타데이터가 기존 파일과 동일. JLC BOM/CPL도 원본과 동일. 기구 작업으로 전기 설계 변경 없음.
- KiCad 10 호환을 위해 넷리스트 줄바꿈 파싱, FP_TEXT 이름 변경, Flip 방향 enum, 프로젝트 설정 분리 저장을 보완했다. Mac 폰트 컬렉션의 인덱스를 읽도록 기존 글리프 검사를 보완했다.
- KiCad 10 재저장으로만 달라지는 PCB/넷리스트/PDF/XLSX는 비교 검증 후 기존 KiCad 7 형식 산출물을 유지했다. 회로/PCB 원본 직접 수정 없이 생성기 검증만 수행했다.
- 원본 PCB의 KiCad 10 DRC: **clearance 0, courtyard 0**, 미연결 327(배선 전). 기타 426 = silk_over_copper 168, silk_overlap 150, lib_footprint_mismatch 96, silk_edge_clearance 11, lib_footprint_issues 1. 전체 DRC 0 또는 주문 가능이라고 판정하지 않는다.
- 기구 생성기 → STEP → 4쪽 도면 PDF → JLC 기구 패키지 재생성. 조립 시방서 24쪽 및 19단계 그림 재생성. 엔드캡 도면과 시방서 육안 확인.
- 조립 검사 **31건: OK 30 / NG 0 / WARN 1**. WARN은 에폭시 유동·기포가 형상만으로 확인되지 않는다는 뜻이다.

## 내가 결정할 것 (두텍)

실제 M12 및 300 pF 센서 품번, 사용/시험 압력, 오일·주위·전자부 온도, 에폭시와 접액부/홀더 재질을 확정해야 한다. 이 값이 확정되면 해당 구매품 도면과 실제 조립 시험으로 남은 조건을 닫을 수 있다. 현재 기구 변경에 대한 추가 승인은 요청하지 않으며, 제조 주문은 진행하지 않았다.
