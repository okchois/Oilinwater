## 1. 요약

- **업계 표준 방식은 "박막 고분자 정전용량형 습도 센서로 수분 활동도(aw)를 측정 → 온도 보상 → 용해도 곡선으로 ppm 환산"** 입니다. Vaisala MMT330/MMT162, E+E EE381, HYDAC AS1000 등 주요 제품 모두 이 방식입니다.
- aw(또는 %RS, 상대포화도)는 **오일 종류·열화와 무관하게** "유리수(free water)가 생길 위험"을 직접 알려주므로 1차 측정량으로 쓰고, ppm은 오일별 계수(A, B)가 필요한 **2차 계산값**입니다.
- 개발 난이도의 핵심은 전자회로가 아니라 **①센서 소자의 오일 내 장기 안정성, ②교정/검증 체계(습도 발생기 + 칼피셔 적정), ③고압·고온 프로브 기구 설계, ④현장 인증(EMC, 방폭, HART)** 입니다.
- 추천 전략: **센서 소자는 검증된 OEM 소자(IST AG MK33-W, E+E HC 계열 등)를 구매**하고, 자체 역량은 CDC 측정 회로·온도 보상·교정 알고리즘·프로브 기구·통신(4–20 mA/HART/Modbus)에 집중.
- 1차 타깃 시장으로 **유압/윤활유(산업·건설기계)** 는 요구 정확도(±2–3 %RS)와 인증 부담이 낮아 진입이 쉽고, **변압기유**는 ppm 정확도·전력사 인증 요구가 높은 대신 부가가치가 큽니다.
- 참조 코드: [`tools/moisture_calc.py`](../tools/moisture_calc.py) (aw ↔ ppm 환산, 용해도 계수 피팅).

## 2. 기본 개념

### 2.1 물의 세 가지 상태

| 상태 | 설명 | 영향 |
|---|---|---|
| **용존수 (dissolved)** | 분자 단위로 오일에 녹아 있음. 포화점 이하 | 눈에 안 보임. 절연유에서는 절연파괴전압(BDV) 저하, 종이 절연 열화 가속 |
| **유화수 (emulsified)** | 포화점을 넘어 미세 물방울로 분산 | 오일 혼탁, 윤활막 파괴, 부식, 첨가제 가수분해 |
| **유리수 (free)** | 분리되어 바닥에 고임 | 부식, 캐비테이션, 미생물 번식, 절연 사고 |

→ 트랜스미터의 1차 목적은 **"포화점(aw = 1)에 얼마나 가까운가"** 를 실시간으로 알려 유화/유리수 발생 전에 경보하는 것입니다.

### 2.2 측정 단위

| 단위 | 정의 | 특징 |
|---|---|---|
| **aw (water activity)** | 0–1. 오일 내 물의 화학 포텐셜을 순수한 물 대비 비율로 표현 | 공기의 상대습도(RH)와 같은 개념. 오일 종류 무관 |
| **%RS (relative saturation)** | aw × 100 | 유압·윤활 업계에서 주로 사용 |
| **ppm (mg/kg, w/w)** | 오일 질량 대비 물의 질량 | 실험실 칼피셔(KF) 결과와 직접 비교. 오일별 용해도 계수 필요 |

**중요:** 같은 20 ppm이라도 20 °C 광유 변압기유에서는 aw≈0.36 이지만 60 °C에서는 aw≈0.08 입니다 (5장 참고). 온도가 떨어지면 ppm이 그대로여도 aw가 올라가 유리수가 생길 수 있습니다.

### 2.3 "Water cut"과의 구분

원유·생산정(油井)의 **water cut (0–100 % 함수율)** 측정은 전혀 다른 제품군입니다 (마이크로파/RF 유전율, 감마선 등; Emerson Roxar, Phase Dynamics, AGAR 등). 이 보고서는 **ppm~포화점 범위의 미량 수분** 측정(윤활유·유압유·절연유·연료)을 대상으로 합니다. 향후 water cut으로 확장하려면 별도 센서 원리가 필요합니다.

| 광섬유/FBG 코팅 센서 | aw | – | 전기적 절연(변압기 내부) | 상용 성숙도 낮음 | ★ 연구 단계 |

**결론:** 정전용량형 aw 센서 + 정밀 온도센서 조합을 기본 플랫폼으로 채택. 필요 시 향후 모델에서 유전율/전도도 센서를 추가해 오일 열화 지표(산화, 오염)까지 확장.

### 4.1 정전용량형 센서의 동작

- 전극 사이에 흡습성 고분자(폴리이미드 등) 유전막이 있고, 상부 전극은 물 분자가 투과 가능한 다공성 박막.
- 오일 속 물의 활동도와 평형이 되도록 고분자가 수분을 흡수 → 유전율 변화 → 정전용량 변화 (예: 150–300 pF 기저, 0→100 % 범위에서 수십 pF 변화).
- 기체(공기)에서 교정한 RH 곡선이 **오일 내 aw 측정에도 그대로 적용**된다는 것이 이 방식의 핵심 장점 (물의 화학 포텐셜이 평형이므로). 단, 오일 성분이 고분자에 흡착되어 생기는 **오프셋/감도 변화**가 실제 오차의 주원인 → 소자 선택과 오일 내 장기 시험이 중요.

## 5. 핵심 계산: aw ↔ ppm 환산

### 5.1 용해도 모델

오일의 포화 수분량(용해도) Ws는 온도에 대해 반 대수 관계:

```
log10( Ws [ppm] ) = A + B / T        (T: 켈빈, B < 0)
ppm = aw × Ws(T)
%RS = aw × 100
```

- 광유계 변압기유 대표값: **A = 7.0895, B = −1567** (log S₀ = 7.0895 − 1567/T)
- 이 계수로 계산한 포화 수분량 (참조 코드 실행 결과):

| 온도 | 20 °C | 40 °C | 60 °C | 80 °C |
|---|---|---|---|---|
| Ws (ppm) | 55.5 | 121.8 | 243.2 | 449.0 |

- 예: 20 ppm 수분 → 20 °C에서 aw 0.361, 60 °C에서 aw 0.082.
- **에스테르유(천연/합성)는 용해도가 광유의 수십 배**(상온에서 약 1,000 ppm 이상 수준)이므로 계수가 완전히 다릅니다. 유압유·윤활유도 첨가제에 따라 크게 달라집니다.
- 오일이 산화·열화되면 극성 물질이 늘어 용해도가 증가 → 같은 오일이라도 **수명 중 계수가 변함**. 그래서 aw를 1차량으로 삼는 것이 안전합니다.

### 5.2 제품에 필요한 기능

1. 오일 라이브러리(광유 변압기유, 에스테르, 대표 유압유 등)의 A, B 계수 내장
2. 사용자 계수 입력 (Modbus/HART/설정 SW)
3. **현장 계수 산출 기능**: 서로 다른 두 온도 이상에서 샘플을 채취해 KF로 ppm 측정 → 트랜스미터의 aw·T와 함께 A, B를 피팅 (`tools/moisture_calc.py`의 `fit_coefficients`)
4. 변압기용: 오일-종이 평형 곡선(Oommen 곡선 등, CIGRE TB 741 참고)을 이용한 **종이 절연 수분(%) 추정**은 부가기능으로 차별화 가능. 단, 온도 과도 상태에서는 평형이 성립하지 않으므로 필터링/평형 판단 로직 필요.

## 10. 펌웨어/알고리즘

1. **측정 체인**: C_raw → 기저·케이블 보상 → 온도 의존 교정 다항식 `aw = f(C, T)` (2차원 교정 테이블/다항식) → 필터링 → aw, %RS
2. **온도 보상**: 소자의 용량-습도 특성은 온도 의존 → 여러 온도(예: 20/40/60/80 °C)에서 교정해 2D 보정.
3. **ppm 환산**: `ppm = aw × 10^(A + B/T)` + 오일 라이브러리 + 사용자 계수.
4. **포화/응결 처리**: aw ≥ 0.95 근처에서 히스테리시스·복귀 지연 고려, "유리수 위험" 상태 플래그.
5. **평형 판단**: 온도 변화율(dT/dt)이 크면 aw/ppm 값의 신뢰도 낮음 → 이동평균·안정 플래그 제공 (변압기 부하 변화 시 중요).
6. **진단**: 소자 단선/단락, 용량 범위 이탈, 온도센서 이상, 내부 온도 과열, EEPROM CRC → NAMUR **NE43**(전류 알람), **NE107**(상태 분류: Failure/Check/Out of spec/Maintenance).
7. **통신**: Modbus RTU 레지스터 맵(float32, 상태, 계수, 교정일), HART 7 명령(Universal/Common Practice/Device Specific), 향후 IO-Link(유압 시장) 검토.
8. **보안/무결성**: 교정 데이터 서명·CRC, 펌웨어 업데이트 시 교정 보존, 설정 변경 이력.
9. **재교정 지원**: 현장 1점/2점 조정(염포화 용액·기준 프로브 비교), 교정 만료 알림.

## 11. 교정 및 시험 방법

### 11.1 1차 교정 (기체 중, aw = RH/100)

- **이압식(two-pressure) 또는 혼합식 습도 발생기** + 냉각식 노점계(기준기, 국가표준 소급) — KRISS(한국표준과학연구원) 또는 KOLAS 인정 교정기관 소급.
- 보조: **포화 염 용액** (25 °C 기준 대략값) — LiCl 약 11 %RH, MgCl₂ 약 33 %RH, NaCl 약 75 %RH, K₂SO₄ 약 97 %RH. 현장/생산 점검용.
- 다온도 교정용 항온조(챔버) 필요.

### 11.2 오일 중 검증

- 오일 순환 루프(히터/칠러, 수분 주입·건조 장치) 구성 → 트랜스미터 aw·T 기록 + 동시 샘플링 KF 적정.

## 16. 차별화 기회

1. **IoT/클라우드 연계**: Modbus TCP/MQTT 게이트웨이, LoRaWAN/NB-IoT 무선형, 추세 기반 예지정비(드라이어 작동 시점 예측).
2. **변압기 특화 분석**: 오일 aw/온도 → 종이 절연 수분 추정, 기포 발생 온도(bubbling inception) 위험 경고, 동적 평형 판단.
3. **오일 종류 자동 학습**: 여러 온도에서의 aw–T 데이터 + 주기적 KF 입력으로 계수 자동 갱신.
4. **복합 센서**: aw + 유전율/전도도(오일 열화·산화) + 온도를 한 프로브에 → "오일 컨디션 센서"로 확장.
5. **스마트 교체형 프로브**: 교정 데이터를 프로브에 저장(Vaisala Indigo/MMP8 방식) → 현장에서 프로브만 교환·교정 서비스 모델.
6. **IO-Link / CAN(J1939)**: 모바일 유압·건설기계 OEM 대응.
