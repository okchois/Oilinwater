# HMT500(260313A) 회로 확정 전 3중 검토 + RS-485 몰딩 후 펌웨어 업데이트 검토

작성 2026-09-30 · 대상: 회로도 v0.8 (`hardware/kicad/gen_hmt500.py`), PCB 배치 rev 3 (배선 전)

## 검토 방법

서로 독립된 검토 3회 + 부트로더 검토 1회. 각 검토는 넷을 하나씩 따라가며 제조사 데이터시트 원문과 대조했다.

| 검토 | 범위 | 대조한 원문 |
|---|---|---|
| 1 전원·보호 | M12 입력 → 보호(GDT·TVS·초크) → eFuse TPS26600 → 벅 LMR36006 → LDO → 각 IC 전원, 4–20 mA 출력단, 샤시·접지, 서지·역접속·오배선 | TI SLVSDG2G, SNVSB48C, SLVSFE3C, SBAS528D, SBVS338H, SLVSEG2B, OPA197 |
| 2 측정·MCU | PCAP04, ADS1220 Pt1000, STM32G0B1 핀·AF, SPI 모드, DAC SPI 게이트, RS-485, J1·J2·J3 핀 배정 | TI SLLSF20B, SBAS501D, SBAS528D, ScioSense PCAP04 DS-6, ST 공개 핀 데이터(GitHub XML) |
| 3 일치·제조성 | 심볼 핀 ↔ 풋프린트 패드 ↔ 데이터시트 패키지, 정격(전압·유전체·전력), 넷 무결성, 배치(발열·샤시 간격·배선 가능성) | 위 TI·ScioSense 원문 + KiCad 라이브러리 |
| 부트로더 | 몰딩 후 M12(전원 + RS-485)만으로 펌웨어 업데이트 가능 여부 | TI SLLSF20B, `docs/rs485-bootloader-design.md`, `firmware/bootloader/` |

공통: `check_netlist.py` 74 / 74 넷 일치, `tests.test_kicad_gen` 통과. 막힌 사이트: st.com, littelfuse.com, bourns.com, we-online.com, jst-mfg.com → 해당 값은 "확인 필요".

## 결론

**아직 확정하면 안 됩니다.** 모든 IC의 핀 번호·패드는 데이터시트와 일치하고 회로 구조도 맞지만, 서지·과전압 복귀·벅 입력 콘덴서 등 **몰딩 후에는 고칠 수 없는 항목**이 있습니다. 아래 A는 대부분 부품 1–2개 추가·값 변경으로 해결됩니다.

## F. RS-485 펌웨어 업데이트 (몰딩 후)

**가능 — 단, A5(DE 풀다운)와 아래 펌웨어 조건이 있어야 "벽돌 안 됨"을 보장.**

- **방식:** 플래시 앞 32 KB 자체 부트로더(`docs/rs485-bootloader-design.md`), USART2 PA2/PA3 + 하드웨어 DE(PA1 AF1). M12의 전원·RS-485만 사용 → 몰딩 후 BOOT0·NRST·SWD 불필요.
- **ST 내장(ROM) 부트로더는 사용 불가:** USART2를 보긴 하지만 DE(PA1)를 켜지 못해 응답 불가. 옵션 바이트는 nBOOT_SEL = 1, nBOOT0 = 1 유지.
- **벽돌이 안 되는 이유:** 부트로더 영역은 지우지 않고 쓰기 보호(WRP). 펌웨어 헤더를 **마지막에** 기록 → 정전·통신 끊김·손상 이미지면 헤더가 없어 다음 부팅에 부트로더에 머묾 → 다시 업데이트. 다른 하드웨어용 이미지는 하드웨어 ID로 거부. 교정·설정은 펌웨어 영역 밖.
- **추가해야 할 펌웨어 (CRC는 맞지만 멈추는 펌웨어 대비):**
  1. 전원 켠 뒤 약 1 초 복구 창 (고정 19200 8E1 + 저장 설정, 매직 요청에만 반응) — 전원이 M12에 있으므로 전원 재투입으로 항상 진입
  2. 부팅 확인 카운터 (백업 레지스터, 3회 미확인 또는 IWDG 리셋 반복 → 부트로더 유지)
  3. 하드웨어 워치독 리셋부터 동작 (IWDG_SW = 0), 페이지 지우는 사이 갱신
- **옵션 바이트:** RDP 레벨 1 (IAP 가능), 레벨 2 금지. WRP 0–15쪽. BOR 높은 문턱.
- **업데이트 중 4–20 mA:** 들어가기 전 NAMUR 고장 전류(≤ 3.6 mA) 또는 마지막 값 유지(설정). 부트로더에도 DAC 최소 드라이버.
- **남는 위험:** 단일 슬롯(업데이트 끝날 때까지 측정 없음), 업데이트 중 버스 점유(19200 bps에서 약 76 s), 부트로더 자체 버그(몰딩 전에 충분히 검증, 현장에서 부트로더는 갱신하지 않음).
