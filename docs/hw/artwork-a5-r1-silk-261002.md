# HMT500 A5-R1 실제 실크 수정

## 바뀐 것

사용자 요청에 따라 PDF에만 표시했던 방식 대신 PCB 생성기에서 실제 F.SilkS/B.SilkS 레퍼런스를 수정했다. A5 배선/부품/패드/회로/기구 사양은 유지한다.

- 문자 폭 0.8 → 0.6 mm, 높이 0.8 mm, 선폭 0.12 mm.
- 가까운 위치와 0/90° 방향을 탐색한다. 일반 배치는 다른 부품보다 해당 부품이 가까운 위치만 허용한다.
- 별도 지시선 10개: D30, D51, U1, U13, C16, C2, C24, C36, C60, FB1.
- 실제 표시 56/110개, 공간 부족으로 숨김 54개. 모든 번호의 실크 인쇄를 완료한 상태가 아니다.
- PDF는 실제 PCB 실크를 내보내며 부품번호를 별도로 덧씌우지 않는다. 이전 *_REF.pdf는 제작 근거로 사용하지 않는다.

## 검사

전체 재생성, 넷리스트 81/81 일치, 테스트 33개 통과. DRC 오류 0, 미연결 0, 실크 관련 경고 0. 기존 C44/D1 라이브러리 차이 경고 2개 유지. 기존 A5 대비 트랙·비아 및 패드 위치/넷을 프로그램으로 대조해 동일함을 확인했다. Gerber는 마스크 영역 차감 옵션으로 생성한다.

## 남은 위험

숨긴 번호: C12, C13, C14, C21, C22, C23, C27, C28, C29, C30, C4, C41, C42, C44, C45, C46, C5, C50, C51, C52, C54, C55, C57, C58, C8, D3, D40, D41, R11, R14, R15, R17, R18, R19, R20, R32, R4, R41, R51, R52, R6, R8, R9, U10, U12, U2, U7, U8, U9, C62, C63, C20, C47, D2.

표시를 위해 패드를 침범하거나 다른 부품 옆으로 번호를 옮기지 않았다. 110개 모두 인쇄하려면 추가 실크 정리 또는 배치 공간 확보가 필요하다. 0.12 mm 선폭은 일반 실크 권고 0.15 mm보다 가늘어 고정밀 인쇄 공정 확인이 필요하다. 제조사 안내: https://www.jlc.com/portal/q6i10417.html (고정밀 0.1 mm 선폭/0.8 mm 높이; 실제 6층 적용 조건 확인 필요). 표준 안내: https://jlcpcb.com/blog/pcb-silkscreen .

기존 0.15 mm 비아/POFV 혼용 DFM, 미확정 LCSC(C61/R9/R52), 온도·몰딩·EMC 검증 및 주문 보류는 유지한다.

## 내가 결정할 것

이번 실크 수정에 필요한 추가 결정은 없음. 제조 주문은 아직 진행하지 않았다.
