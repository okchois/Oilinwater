# HMT500(260313A) PCB 부품 배치 — 배선 전 승인용

**상태: 배치 rev 4 (회로도 v0.9 · 기구 Rev H, 2026-09-30).** 배선 전. 부품 114개 (윗면 50, 아랫면 64) — 결정 #37 VAO 벅·DAC 클램프/CMP 추가. 이전: 104개 (윗면 45, 아랫면 59) — 외부 검수 반영(결정 #35): D3·D60·D61 추가, C7 삭제, U11 VSSOP, 저전압 R·C 37개 0402.

**rev 4 변경 (3중 검토 D1–D6):**
- PCB가 기구 Rev H에서 x −2 (KiCad 좌표는 그대로). 가장 좁은 보어는 하우징 나사 골 Ø24.9 — 모든 부품 높이 여유 ≥ 0.5.
- J5 샤시 구멍을 가장자리 쪽(y 7.4)으로 옮기고 둘레 3.3 mm(구멍 중심 ~ 코트야드) 양면 부품 금지 (손납땜 브리지 방지).
- 샤시 부품(GDT1·C3·R2)은 다른 부품과 코트야드 0.5 mm 더 띄움 + 넷클래스 CHASSIS 동박 간격 1.0 mm (몰딩 안), 선폭 0.5. 벅 핀 콘덴서 다음 순서로 앞 구역(입력 보호부 옆)에 모음 — MCU·DAC에서 떨어짐. J5 패드까지 11–17 mm (배선 때 CHASSIS 전용 선).
- DAC8760 ×2를 측정부(PCAP04·ADS1220) 밑에서 x 42–48로 옮김 (측정부와 약 5 mm 이상).
- 배치기에 핀 지정 기준 `("pin", IC, 핀번호)` 추가. U2는 180° 고정(BOOT·VCC 핀이 J5 반대쪽), U8은 U7과 대칭(180°, ISET·REF 핀 안쪽). MCU 디커플링 C14/C20/C15는 U4 핀 4–6 바로 아래 아랫면. TPS26611 +Vs 폴로워 Q1·R50·D50·C53 추가.
- 핀에 붙어야 하는 부품을 해당 IC 바로 다음 순서로 배치: 벅 C16/C17 220 nF (0.3 mm), C8·C9, C5 벌크; eFuse D2(TVS3301)·C2·C1 (0.2–0.4 mm); LDO C26; DAC ISET-R·REF C·AVDD R/C (0.2 mm); TPS26611 +Vs C46/C56.
- 검토 권장 DNP(DAC 부스트, HSE 크리스털, 센서선 ESD)는 효과 있는 위치에 자리가 없어 넣지 않음 (결정 #32).

## 하네스 통로 규칙 (윗면)

rev 3: 링 뒤(x ≥ 59) 부품 높이 한계는 Ø20(링을 뒤에서 끼움). PCB 폭 23 구간은 x 63.4에서 끝.

플러그 몸체와 꽂는 거리·잡는 공간만 완전히 비우고, 전선만 지나가는 곳은 낮은 부품을 허용한다.

| 구간 (x, mm) | \|y\| | 규칙 | 근거 |
|---|---|---|---|
| 14.5–22.5 | ≤ 3.5 | 높이 ≤ 1.0 | W-1 선 중심 z 2.2, 굵기 0.6 → 선 아래 1.9 |
| 22.5–30.5 | ≤ 3.5 | 부품 금지 | J3 플러그(26.5–30.5) + 꽂는 거리·잡는 공간 4 mm |
| 58.5–71 | ≤ 6.4 | 부품 금지 | J1 플러그 + 잡는 공간 + 턴버클 때 남는 W-2 선(약 29 mm)이 접히는 곳 (rev 3) |

rev 2에서 옮긴 것: SWD Tag-Connect J2(높이 0, 프로그래밍은 하네스 꽂기 전)를 W-1 선 아래로 → 비워진 앞쪽 윗면에 LDO U3·C12·FB1·C13을 올려 +3V3A를 측정부에 바로 공급. eFuse U1은 방열 비아가 윗면에 RTN 동박 패드를 만들므로 윗면 부품이 없는 J3 플러그 통로 바로 아래에 둠. 벅 루프(U2–L2–C10·C6)를 붙임.

## 배치 원칙 (좌표: 앞 = 센서 x 14.5, 뒤 = M12 x 71)

| 구역 | 윗면 | 아랫면 |
|---|---|---|
| 앞 (x 18–30, 바디 Ø22 안) | J5 샤시 선 구멍, C3·R2, J2 (W-1 선 아래), LDO·FB1 (+3V3A), 측정 수동부품 | eFuse (플러그 통로 아래), 벅 LMR36006·L2·출력 C |
| 가운데 (x 30–52, 하우징 Ø27 안) | J3 (x 30.5–34.9, 입구 앞), PCAP04·ADS1220을 J3 양옆에 (센서선 최단), MCU (x 42.8), RS-485, SCLK 게이트 U14, 출력 TVS D30/D40 (J1 OUT 핀 바로 앞) | DAC8760 ×2 (발열 부품 → 센서 쪽에서 떨어뜨림), TPS26611 ×2, OPA197 ×2 |
| 뒤 (x 52–71, 링·엔드캡) | J1 (x 54.4–58.5, 입구 뒤), 10 Ω 2512 R30/R40 (J1 양옆). **가운데 \|y\| ≤ 6.4는 비움** (J1 플러그 + M12로 가는 선) | CM 초크 L1 (높이 5 → 링 구역 가운데), TVS D1·D2, R1(MELF) |

입력 흐름: J1 VIN → L1 → D1 / R1 → D2·C1 → eFuse U1 (앞쪽, 플러그 통로 아래) → VIN_P → 벅·DAC·출력 스위치.
출력 흐름: DAC → TPS26611 → R30/R40 (윗면) → TVS → J1.

## 확인된 문제 · 다음 단계에서 다룰 것

1. ~~J5 스프링 접점 미접촉~~ → rev 3에서 샤시 선 납땜 구멍으로 교체 (결정 #27). GDT1은 J5에서 약 25 mm (아랫면 가운데) — 배선 때 CHASSIS를 넓은 선으로.
2. 빽빽함: rev 3에서 아랫면 685 mm²로 줄어 배선 여유 생김.
3. U1(아랫면) 방열 비아의 윗면 동박 패드(RTN)는 J3 플러그 통로 아래 — 평평한 동박이라 기구 간섭 없음 (일부러 이 자리에 둠).
4. 배선 때 조정: DAC +3V3 디커플링 C44·C54, VIN_P C45·C55를 핀에 더 붙이기; 실크 글자 정리.
