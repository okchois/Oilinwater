## 확인된 문제 · 다음 단계에서 다룰 것

1. **J5 샤시 스프링 접점이 하우징에 닿지 않음 (중요):** J5 패드 위치에서 하우징 Ø27 내면까지 높이 = 10.8 mm, S1941-46R 자유 높이 = 7.25 mm → **3.6 mm 모자람**. 보드 어디에 두어도 7.25 mm로는 닿지 않는다 (가장자리 최소 ≈ 9.8 mm). → 다음 조립성 검토(시뮬레이션)에서 대안 비교 후 결정.
2. 빽빽함: 아랫면 약 80 %. 배선 여유를 위해 J5 대안이 작은 것이면 아랫면 약 70 mm² 확보.
3. U1(아랫면) 방열 비아 풋프린트의 윗면 동박 패드(RTN)가 J3 플러그 통로 아래 x 27–29에 있음 — 평평한 동박이라 기구 간섭 없음.
4. 배선 때 조정: DAC +3V3 디커플링 C44·C54, VIN_P C45·C55를 핀에 더 붙이기; 실크 글자 정리.
