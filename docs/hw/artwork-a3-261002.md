# HMT500 PCB A3 — 6층·비아 축소 반영 결과

2026-10-02 · **미완성 초안, 제작/주문 불가**

## 바뀐 것

두텍의 “6층. 비아홀 축소.” 지시를 결정 #45로 반영했다. A2의 4층에서 A3의 6층으로 변경했다. 회로 v0.10, 110개 부품/81개 넷, 기구 Rev I 외형 56.5×23 mm와 명목 두께 1.6 mm는 유지했다. A1/A2 배치·배선 스냅샷도 보존했다.

| 층 | 용도 |
|---|---|
| L1 / F.Cu | 부품·신호·전원 |
| L2 / In1.Cu | GND 기준면 |
| L3 / In2.Cu | 신호·전원 |
| L4 / In3.Cu | 신호·전원 |
| L5 / In4.Cu | GND 기준면 |
| L6 / B.Cu | 부품·신호·전원 |

- 축소 신호 비아 92개: 패드 0.30 mm / 드릴 0.15 mm. 일반 관통 비아이며 블라인드/매립 비아는 적용하지 않았다.
- 혼잡한 저전압 디지털 신호는 선폭·간격 0.10/0.10 mm를 허용했다. 전원·서지·방열 비아는 기존 크기를 유지했다. 별도 SPI_MISO 시험 인출 비아 1개는 0.35/0.20 mm이다.
- RTN–GND 0.30 mm, RTN–다른 넷 0.25 mm, CHASSIS 간격 1.0 mm를 유지했다. RTN 아래 분리 영역을 네 내층 모두에 적용했다.
- JLC06161H-2116A의 공개 적층을 기준으로 생성기를 변경했다. 외층 동박 0.035 mm, 내층 0.0152 mm. 동박 사이 절연체는 0.1164 / 0.13 / 0.9328 / 0.13 / 0.1164 mm이다. 중앙 0.9328 mm는 프리프레그 0.1164 + 코어 0.7 + 프리프레그 0.1164의 합을 KiCad에서 하나로 표현한 값이다. **완성 두께와 실제 적층 구성은 제조사 확인 필요**이며, nominal 1.6 mm를 모든 층 두께의 정확한 산술 합계라고 주장하지 않는다.

경고는 제외 처리하지 않았다. 라이브러리 차이 2건은 기존 C44/D1 실크→Fab 변경이다. DRC 미연결 항목과 dangling 경고는 서로 다른 집계다. 기구 형상·부품 배치는 A2와 같으며 이번에는 기구 시뮬레이션을 새로 실행하지 않았다. KiCad 네이티브 회로도 비교 오류 0이라는 의미는 아니며, 별도 원본 패드–넷 검사를 통과했다.

## 남은 위험

1. **접지 4건·3.3 V 전원 3건·OVP 분압 2건 등 총 15건 미연결.** 입력 보호·전원·측정 기능이 성립하지 않는 상태이므로 전원을 인가하거나 주문하면 안 된다.
2. 남은 핀 인출은 MCU와 반대면 DAC의 패드 겹침, ADC 주변 배선, eFuse–CHASSIS 주변 공간에 막혀 있다. 층과 홀 크기 변경만으로 전부 해결되지는 않았다. 다음 배선 작업은 MCU/ADC/입력 보호의 막힌 인출부를 중심으로 주변 배치와 기존 배선을 함께 수정해야 한다.
3. U6 SPI_MISO 인출 비아(120.1,109.675 mm)와 C64 GND 연결 비아(143.344,100.178 mm)는 SMD 패드와 겹치는 시험 배치이다. 일반 텐팅만으로 생산 승인하지 않는다. 기존 DAC PowerPAD 비아와 함께 납 흡수·솔더 페이스트 설계를 검토하고, 필요한 패드 내 비아는 충전·동도금(POFV) 또는 패드 밖 재배치로 마무리해야 한다. JLC 공개 POFV 홀 범위는 0.2–0.5 mm이며 **0.15 mm 일반 비아와 0.2 mm POFV의 혼용 가능성/견적은 확인 필요**이다. 현재 PCB 파일만으로 제조사에 POFV를 지정한 상태는 아니다.
4. 모든 연결을 마친 뒤 전원·서지 경로 선폭/우회, GND 리턴, 디커플링 루프, 몰딩 발열을 검토해야 한다. DRC 오류 0은 전기 성능이나 제조 승인을 보장하지 않는다.
5. 작은 드릴은 추가 공정 비용 대상이다. 제조 DFM, BOM 미확정 2줄, CPL 회전, 제품 온도·몰딩 재료·서지/정확도 시험은 계속 미결이다.

## 내가 결정할 것

6층·비아 축소는 이미 승인받아 반영했다. 같은 승인을 다시 요청하지 않는다. 현재 초안으로 주문을 결정할 단계가 아니며 추가 층수/더 작은 홀을 요청하지 않는다. 기존 온도·몰딩 재료 결정은 별도 결정 기록을 따른다.

## 재현 및 근거

- `hardware/kicad/rebuild_artwork.sh`: 기본 A3. 이전 A1/A2는 HMT_ARTWORK로 지정한다.
- `placement/artwork_A3.json`, `routing/artwork_A3_draft.json`: 배치·배선 원본. 배치/층수가 다르면 복원을 거부한다.
- `HMT500(260313A)_artwork_drc.json`, `artwork_check.json`: 검사 원문. 재생성 성공은 제작 승인이 아니다.
- 검토 ZIP은 회로/PCB/생성기/검사 자료이며 **거버·주문 패키지가 아니다.**
- 제조 기준: [JLCPCB PCB capabilities](https://jlcpcb.com/capabilities/pcb-capabilities/), [공개 적층](https://jlcpcb.com/impedance), [POFV 공정 설명](https://jlcpcb.com/news/free-via-in-pad-6-20-layer-pcbs-pofv). 실제 주문 가능 조건은 최종 DFM에서 확인한다.
