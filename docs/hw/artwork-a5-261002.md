# HMT500 PCB A5 — 배선 연결 완료, 제조 검토용

2026-10-02. A4를 보존하고 A5 배치·배선 입력을 따로 저장했다. **미연결 0, 일반 DRC 오류 0**을 생성기 전체 재실행 후 확인했다. 제조사 DFM과 실물 성능 검증은 남아 있으므로 **발주 보류**다.

## 바뀐 것

- A4의 VIN_P 1건, RS485_A_EXT 2건, SWCLK 1건, OUT1_SGOOD 1건을 모두 연결했다. 주변 DAC 통신·리셋·3.3 V 배선도 함께 정리했다.
- 6층 및 0.30/0.15 mm 신호 비아 유지. **In1은 GND 전용, In4는 GND 동박과 검토된 7개 넷을 혼용**한다. In4까지 GND 전용이던 A4와 다르다. 회로 v0.10, VAO 16.1 V, 입력 12–28 V, RL ≤ 500 Ω 조건과 기구 Rev I, 110개 부품 배치는 바꾸지 않았다.
- In4 배선 길이: +3V3 4.557, VIN_P 11.628, SWCLK 5.455, OUT1_SGOOD 16.657, RS485_A_EXT 9.611, DAC2_LATCH 7.152, DAC_MOSI 30.041 mm. 짧은 교차만 있는 것은 아니다. `artwork_a5.py`에서 허용 넷과 레이아웃 회귀 한도를 제한한다.
- 분리됐던 GND 동박을 비아 2개로 연결하고, 신호층 전환 주변에 GND 귀환 비아 5개를 추가했다. In1 GND는 채움 폴리곤 1개(967.460 mm²), In4는 2개(986.648 mm²)다. 전층 GND 연결 분석 및 KiCad 미연결 검사를 통과했다. 이것이 고주파 귀환 임피던스나 EMC 합격을 보증하지는 않는다.
- 사용하지 않는 배선 가지를 정리하여 dangling track/via 경고도 0으로 만들었다.
- A5 재생성은 일반 DRC 오류뿐 아니라 미연결이 있어도 실패하도록 강화했다. 전용 배치 JSON, 배선 스냅샷, 검사·제조 검토 내보내기 스크립트로 재현한다.

## 남은 위험과 주문 전 확인

1. **제조 공정:** 0.15 mm 관통 비아와 0.20 mm 이상 POFV 충전·동도금 혼용, 실제 6층 적층·동박 두께·드릴 공차는 제조사 DFM 확인 필요. POFV 목록은 패드 바운딩 박스 겹침에 따른 보수적 후보이며 제조사 확정 목록이 아니다.
2. **부품/실장:** C61, R9/R52의 LCSC 번호가 미확정이다. JLC 실장 미리보기에서 양면 부품 방향·J2/J5 제외 처리도 확인한다.
3. **전기 성능:** In4 신호/전원 혼용 및 긴 DAC 통신 경로 때문에 실제 SPI 에지·링잉·센서 잡음·EMC/서지 사전시험이 필요하다. DRC는 입력/RS-485 서지 에너지에 대한 선폭 적정성, 전원 과도 응답, 발열을 검증하지 않는다. 전원·서지 병목의 제조/시험 검토를 생략하지 않는다.
4. **온도/몰딩:** eFuse RTN 섬과 DAC/벅 발열, 몰딩 유동·열 특성은 실물로 확인한다. 제품 온도 범위와 몰딩 재료는 기존 미결 사항이다.

## 전달 파일과 재현

- KiCad 원본: `hardware/kicad/HMT500(260313A)/`
- 생성 입력: `placement/artwork_A5.json`, `routing/artwork_A5_draft.json`. `draft`는 제조 미승인 상태를 의미하며 미연결 상태를 뜻하지 않는다.
- `hardware/kicad/rebuild_artwork.sh` 기본 A5. A1–A4는 `HMT_ARTWORK`로 선택 가능하다.
- `hardware/kicad/audit_artwork.py`: 비아/POFV/GND·RTN 면적 기록.
- `manufacturing/jlc/export_artwork_review.py`: DRC 재확인 → 거버 6동박층 → 도금/비도금 드릴 → BOM/CPL 대조 → SHA-256 기록.
- `manufacturing/jlc/artwork_A5_review/`: **제조 검토용** 거버 ZIP, 드릴 보고서, BOM, CPL, DRC, 매니페스트. JLC 업로드·주문은 하지 않았다.

## 내가 결정할 것

두텍의 제품 온도 범위와 몰딩 재료 결정이 필요하다. 기존 확정 전기 사양을 바꾸는 추가 결정은 이번 작업에서 하지 않았다. 제조사 DFM이 통과하고 미확정 부품·방향 검토가 끝나면 시제품 발주 여부를 판단한다.
