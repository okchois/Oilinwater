## 3. 선정

### 1순위: **MK33-W mini (200 pF)**

- **오일용 센서입니다.** IST가 MK33을 오일 측정용으로 권장하고, 190 °C까지 쓸 수 있으며 내화학성이 가장 좋습니다. 120 °C 목표에 충분한 여유가 있습니다.
- **크기가 맞습니다.** 5.0 × 3.81 mm라서 캐리어(9.5 × 4.5)에 Pt1000과 함께 올라갑니다. 일반 MK33-W(10.8 mm)는 캐리어보다 깁니다.
- **회로를 바꿀 필요가 없습니다.** 기준 커패시터 220 pF C0G가 센서 용량(200 pF)과 비슷해서 PCAP04 비율 측정에 맞습니다.
- 두텍이 이미 공급받는 "IST MK 센서"와 같은 계열입니다. 공급 품번이 MK33-W mini인지 확인해 주세요.

### 대안: **HYT 271 MK33 (디지털 모듈)**

- 공장 교정된 I²C 출력이라 PCAP04, ADS1220, Pt1000, 기준소자가 빠집니다. 전자부 원가가 약 $10~14 줄고 교정 공정도 단순해집니다.
- 신호가 4선(VDD, GND, SDA, SCL)이라 **HTX99R 4핀 커넥터와 그대로 맞습니다.**
- 대신 모듈 전자부의 최고 온도가 약 125 °C라 120 °C 운전에는 여유가 거의 없습니다. 정확도(±1.8 % RH)도 EE364 수준에 겨우 맞습니다.
- → 오일 최고 온도를 100 °C 이하로 정하면 원가 절감안으로 검토할 가치가 있습니다.

## 4. 설계 반영 사항

| 항목 | 내용 |
|---|---|
| PCAP04 기준 C | 220 pF C0G ±1 % 유지 (MK33-W mini 200 pF). 일반 MK33-W(300 pF)로 바꾸면 270~330 pF로 변경 |
| 측정 방식 | PCAP04 방전시간 측정. IST 권장 교류 주파수(1–100 kHz)와 방식이 다르므로 초기 시험에서 누설·분극 영향 확인 |
| 커넥터 핀 배정 (HTX99R 4핀) | 습도 2핀 + Pt1000 2핀 → **Pt1000이 2선식이 됨** (현재 회로는 4선식). 리드 저항 오차 보정 필요 또는 핀 수 재검토 |
| 교정 | aw 기준점(포화염 또는 습도발생기) + 오일 온도 보상. 공급 로트별 C30 편차(±40 pF)는 1점 교정으로 제거 |

## 5. 확인 요청

1. 현재 공급받는 IST MK 센서의 정확한 품번 (MK33-W / MK33-W mini / 기타)
2. 오일 최고 온도 목표 (120 °C 유지 여부) — HYT 271 모듈안 판단용
3. HTX99R 커넥터 4핀 배정 — Pt1000 2선식 허용 여부
