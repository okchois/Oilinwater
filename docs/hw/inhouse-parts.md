**정리:** 두텍은 **전압 출력 2채널 SPI DAC(DAC7562 / DAC8562 / DAC60502)** 를 쓰고 있습니다. 전압·전류 출력 단은 제품마다 따로 구성한 것으로 보입니다. 지금 HMT500 회로의 **DAC8760 ×2(전압/전류 출력 일체형)** 는 사내에서 쓴 적이 없습니다.

### 2.1 비교

| 항목 | 현재: DAC8760 ×2 | 사내안: DAC7562 (2채널) + 채널별 V/I 출력단 |
|---|---|---|
| 분해능 | 16-bit | 12-bit — 0–24 mA에서 약 6 µA/step (0.025 % FS). 센서 정확도(±0.02 aw ≈ ±2 % FS)보다 100배 이상 세밀 → **충분** |
| 부품 수 | IC 2개 + 수동소자 | DAC 1개 + 채널당 연산증폭기·트랜지스터·정밀저항·모드 전환 스위치 |
| 출력 모드 전환 | 레지스터로 V/I 선택 (한 핀) | 아날로그 스위치로 V/I 경로 전환 (한 핀) |
| 진단 | 개방·과열 알람 내장 | 전류 모드 개방 감지를 따로 만들어야 함 (비교기 또는 MCU ADC로 되읽기) |
| 교정 | 이득·오프셋 레지스터 내장 | MCU 펌웨어에서 교정 (사내 제품과 같은 방식일 것) |
| 전원 | 24 V 단일 전원에서 직접 구동 | 출력단만 24 V(VIN_P), DAC는 3.3 V |
| 1대분 부품가 (추정) | **$15.7 ~ 24.7** | **약 $7 ~ 9** (DAC 약 $3.8 + 출력단 2채널 약 $3 ~ 5) |
| 사내 이력 | 없음 | DAC 있음 (IMX200L, AX7243, HTP1100W). 출력단은 사내 회로 확인 필요 |

→ **사내안이 1대당 약 $8 ~ 15 (1.1 ~ 2.1만 원) 쌉니다.** 전자부 원가에서 가장 큰 항목이라 효과가 큽니다.

**읽는 법**
- **DAC8760/7760:** 출력단이 칩 안에 있어서 회로가 가장 간단하고 진단 기능도 갖췄습니다. 대신 비싸고, 사내에서 쓴 적이 없습니다. 7760은 8760의 12-bit판이라 핀과 레지스터가 같습니다. 12-bit로 충분하니, 이 방식을 유지하더라도 **DAC7760이 원가상 낫습니다.**
- **사내 칩(전압 출력 DAC):** 칩값은 싸지만 전압/전류 출력단을 따로 만들어야 합니다. 그중 **DAC7562(12-bit 2채널, 사내 최다 구매)** 가 가장 쌉니다. DAC60502는 비슷한 가격대의 대안입니다.
- **16-bit(DAC8762 계열, DAC8562)는 필요 없습니다.** 센서 정확도(±2 % FS 수준)에 비해 12-bit(0.025 % FS/step)로도 충분합니다.

### 2.2 권고

1. **DAC는 DAC7562SDSCR로 바꿉니다.** 사내 구매 수량이 가장 많고(200개), 12-bit로 충분합니다. 16-bit가 꼭 필요하면 핀이 같은 DAC8562로 바꿀 수 있습니다.
2. **V/I 출력단은 사내 제품(IMX200L 또는 AX7243)에서 검증된 회로를 그대로 가져오는 것이 가장 안전합니다.** 사내 회로가 전압/전류 선택형이 아니라면, 채널당 "연산증폭기 + 트랜지스터 전류 출력 / 전압 버퍼 + 아날로그 스위치" 구성으로 새로 설계합니다.
3. **출력 오결선 보호(TPS26611)와 TVS·직렬 저항은 그대로 둡니다.** 출력단이 바뀌어도 커넥터 쪽 보호 구조는 같습니다.

**필요한 자료:** IMX200L 또는 AX7243의 아날로그 출력 회로도 (DAC7562 이후 V/I 변환부).
