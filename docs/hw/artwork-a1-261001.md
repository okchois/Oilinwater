# HMT500 PCB A1 아트워크 초안 — 2026-10-01

**배선 미완성 · 제작/주문 금지.** 회로 v0.10, 기구 Rev I를 기준으로 직접 배치 보정과 4층 배선을 진행했다. 현재 KiCad DRC 미연결은 **32건**이다. 간격 오류 0은 배선 완료나 기능 검증을 뜻하지 않는다. 거버·제작용 주문 ZIP은 발행하지 않았다.

## 바뀐 것

- 110개 부품(윗면 51 / 아랫면 59), 기존 기판 외형·기구 Rev I·회로 연결/값 유지. PCB 작업 판은 A1 **초안**이다.
- In1.Cu를 GND 기준면으로 두고 F.Cu / In2.Cu / B.Cu에 배선. 현재 배선 조각 1367개, 비아 137개. 개수는 완료율이 아니다.
- U1 RTN 전용 동박과 내층 분리 영역, RTN–시스템 GND 최소 0.3 mm 규칙 추가. 방열 충분성은 몰딩 시제품 시험으로 확인 필요.
- C16/C8/C62/C63, L2/L3 및 DAC 보상·디커플링 일부를 핀 가까이 재배치. 아래 남은 거리 문제는 해결되지 않았다.
- L1 SRF0905-102Y의 패드 치수와 권선 핀을 제조사 원문과 대조. 기존 랜드 치수 일치: 패드 2×1.2 mm, 중심 ±3.75/±1.27 mm, 권선 1–4 / 2–3.
- L2/L3 SMNR4020 전용 랜드 생성: 패드 0.95×3.3 mm, 안쪽 간격 2.1 mm, 중심 ±1.525 mm, 최대 높이 2.2 mm. 이전 NR-40xx 랜드 치수 수정. 10 µH 정격 DC 전류 1.60 A / DCR 0.165 Ω ±30%, 22 µH 1.05 A / 0.350 Ω ±30%. **정격 DC 전류를 포화 전류로 단정하지 않음; Isat 정의 확인 필요.**
- 생성기·배선 스냅샷으로 같은 PCB를 재현. 배치가 바뀌면 스냅샷 적용을 거부한다. 실크가 조밀한 곳의 참조 글자는 숨기고 조립용 정보는 유지했다. C44/D1의 실크 외곽을 Fab로 옮긴 차이 때문에 라이브러리 비교 경고 2건이 남는다(패드 변경 아님).

## 남은 위험과 다음 배치 작업

1. **MCU–반대면 DAC 주변 비아 접근**: MCU 핀 바깥의 비아 후보가 반대면 DAC 패드/부품과 겹친다. 내측 팬아웃을 시험했으나 전체 연결과 전원 경로까지 만족하는 안으로 완성하지 못했다. MCU와 DAC 주변을 함께 재배치한 뒤 다시 배선해야 한다.
2. **CHASSIS 3건 미연결**: J5–C3–R2–GDT1을 선폭 0.5 mm / 간격 1.0 mm의 전용 경로로 연결해야 한다. 규칙을 낮춰 통과시키지 않았다. GDT1/R2/C3를 J5의 실제 연결 경로에 맞춰 재배치할 필요가 있다.
3. **전원 루프·피드백**: BUCK_SW 넷의 전체 배선 길이 약 13.01 mm, BUCK_FB 약 13.51 mm. U15와 입력/부트스트랩 콘덴서는 면이 다른 부품이 있어 입력 고속 루프와 귀환 경로를 다시 정리해야 한다. 단순 DRC 통과로 스위칭 안정성/EMI를 보장할 수 없다.
4. **측정·AO 경로**: CREF_A 전체 배선 약 18.44 mm, CREF_B 약 1.97 mm로 비대칭. DAC1_CMP 약 9.19 mm, OUT2_P 약 30.35 mm. 기준 커패시터, 보상 커패시터, TPS26611/직렬 저항의 배치와 배선을 더 짧게 해야 한다. 이 길이는 각 넷의 분기를 합한 값이며 특정 두 핀 사이의 최단 거리가 아니다.
5. **GND/아날로그 전원 연결**을 포함해 아래 미연결을 모두 해소한 후, 동박 재채움·DRC·패드–넷 대조를 다시 수행해야 한다. GND 동박을 능동 가드라고 부르지 않는다. PCAP04의 센서 모드와 가드 사용 가능 조건은 데이터시트 및 펌웨어 설정과 함께 검토한다.
6. 제품 온도, 몰딩 후 발열, 서지/오결선 시험, L2/L3 포화 전류 정의, 미확정 JLC 2개 부품 줄 및 BOM/CPL 회전 검증은 여전히 확인 필요.

## 내가 결정할 것

이번 초안 때문에 추가 사양 결정을 요청하지 않는다. 4층, 외형, 입력 12–28 V, VAO 16.1 V, RL≤500 Ω 조건, TPS26611·AO TVS1401·RS-485 TVS3301은 유지했다. 기존 제품 온도 사양 등의 미결 항목은 결정 기록에 남아 있다. **현재 파일로 제작을 진행할 수 없다.**

## 재현

저장소 루트에서 `hardware/kicad/rebuild_artwork.sh`를 실행한다. KiCad 10.0.6의 pcbnew Python과 CLI를 사용했고, Python 환경에는 openpyxl이 필요하다. `KICAD_PYTHON`, `KICAD_CLI`, `TEST_PYTHON`을 지정할 수 있다. 스냅샷은 `hardware/kicad/routing/artwork_A1_draft.json`이다. 배치 지문을 0.0001 mm 단위로 비교하며, 배치가 다르면 재배선이 필요하다. 테스트 성공과 별개로 스크립트 마지막의 미연결 수를 확인한다.

검사 원문: `hardware/kicad/HMT500(260313A)/HMT500(260313A)_artwork_drc.json`, `artwork_check.json`. 제작용 거버 출력 명령을 실행하지 않았다.
