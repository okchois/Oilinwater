# MCU 선정 검토 — HMT500

작성일: 2026-09-26 · 상태: **검토 중** (교차 검토 대기)

현재 회로도는 STM32L431RCT6(LQFP64, −40~85 °C)입니다. 이 문서는 "이 칩이 최선인가"를 요구사항부터 다시 따져 봅니다. 끝에 다른 AI 도구(Codex CLI 등)나 외부 검토자에게 그대로 넘길 수 있는 질문지를 붙였습니다.

> 표의 가격과 온도 등급은 공개 자료와 기억에 기댄 값입니다. **대리점 견적과 데이터시트로 반드시 확인**해야 합니다. "확인 필요" 표시가 붙은 항목은 특히 그렇습니다.

## 1. MCU가 해야 할 일 (요구사항)

| # | 요구 | 근거 | 필수/선호 |
|---|---|---|---|
| R1 | SPI 1개, 칩 선택 4개 (PCAP04, ADS1220, DAC8760 ×2) | 회로 설계서 6절 | 필수 |
| R2 | UART 1개 + RS-485 방향 제어(DE). 하드웨어 DE면 더 좋음 | Modbus RTU 3.5문자 간격, 부트로더 | 필수 (HW DE는 선호) |
| R3 | GPIO 약 20개 (인터럽트 2, 알람·고장 입력 5, LED 1, SWD 2 포함) | 핀 할당표 | 필수 |
| R4 | 플래시 ≥ 128 KB, 가능하면 256 KB. 페이지 단위 소거 | 부트로더 32K + 앱 + 설정 + 교정 | 필수 |
| R5 | 실수 연산: ppm = aw × 10^(A + B/T), 5계수 모델, 교정 다항식 | 측정 주기 약 1 Hz | 선호 (아래 참고) |
| R6 | **동작 온도 −40~105 °C 이상**, 가능하면 125 °C | 오일 최대 120 °C, 전자부 발열 약 1.3 W | 필수 (열해석 후 확정) |
| R7 | 작은 패키지 (7×7 이하) | PCB 폭 23 mm, 한 면 높이·면적 제한 (기구 Rev C) | 선호 |
| R8 | 워치독, 저전압 리셋, 하드웨어 CRC | 현장 무인 동작, 부팅 시 이미지 검증 | 필수 (CRC는 선호) |
| R9 | 국내 수급, 10년 이상 공급, 두텍 개발팀 경험 | 양산·유지보수 | 필수 |
| R10 | 단가 (1k 기준) | 전자부 BOM $36~64 목표 | 선호 |

**R5 다시 보기:** 측정 주기가 약 1 Hz라서 FPU가 꼭 필요하지는 않습니다. FPU 없는 Cortex-M0+도 소프트웨어 실수 연산으로 1초에 한 번 계산하는 데는 충분합니다(코드가 수 KB 늘어나는 정도). 처음 선정 이유에서 "FPU가 필요하다"는 말은 과했고, "있으면 편하다"가 정확합니다.

## 3. 현재 판단 (교차 검토 전)

1. **추천: STM32L431CC 48핀으로 바꾸기.** 단, 105 °C 또는 125 °C 등급을 구할 수 있을 때만입니다.
   - 부트로더 메모리 맵, 하드웨어 DE, CRC, 핀 할당이 그대로라 설계 변경이 가장 적습니다.
   - 64핀 → 48핀으로 PCB 면적이 약 절반이 됩니다.
2. **L431의 고온 등급을 구할 수 없으면:** STM32G0B1(원가) 또는 STM32G431(성능) 중에서 고릅니다. 둘 다 125 °C 등급이 있는 것으로 알고 있으나 확인이 필요합니다.
   - G0: FPU가 없고 플래시가 128 KB라 부트로더 맵을 128 KB에 맞게 다시 짜야 합니다(부트로더 16~24K + 앱 ~96K).
3. **원가를 가장 중시하면:** TI MSPM0G3507을 평가해 볼 가치가 있습니다. UART의 RS-485 하드웨어 DE 지원 여부와 두텍의 개발 경험이 관건입니다.

**가장 큰 결정 요인은 두텍이 이미 쓰는 MCU 계열입니다.** 기존 제품이 STM32라면 STM32 안에서 고르는 것이 개발·생산·유지보수 모두 유리합니다.

## 4. 교차 검토 질문지 (Codex CLI 등에 그대로 전달)

아래 블록을 그대로 복사해 넘기면 됩니다. 저장소 전체를 볼 수 있는 도구라면 파일 경로도 함께 읽도록 합니다.

```text
역할: 산업용 계측기 하드웨어 설계 검토자.

제품: DOTECH HMT500 오일 내 수분 트랜스미터 (E+E EE364급).
- 측정: IST MK 정전용량 습도소자 → PCAP04 (SPI), Pt1000 → ADS1220 (SPI)
- 출력: DAC8760 ×2 (SPI, 전압/전류 선택), RS-485 Modbus RTU (THVD2450)
- RS-485로 펌웨어를 업데이트하는 자체 부트로더 (플래시 맵: BL 32K, 앱 208K, 설정 8K, 교정 8K, 2 KB 페이지)
- 계산: ppm = aw × 10^(A + B/T), 약 1 Hz
- 전원 12~30 V, 전자부 발열 약 1.3 W, 오일 온도 최대 120 °C
- PCB: 57 × 23 mm 1장, 원통 하우징 안. 부품 높이 한 면 5~12 mm
- 참고 파일: docs/hw/mcu-selection.md, docs/hw/hardware-block-design.md,
  docs/hw/circuit-design.md, docs/rs485-bootloader-design.md, firmware/bootloader/

현재 선택: STM32L431RCT6 (LQFP64, −40~85 °C). 검토안: STM32L431CC 48핀 고온 등급.

질문:
1. 위 요구사항에 대해 STM32L431이 최선인가? 더 나은 후보가 있다면 이유와 함께.
2. STM32L431CC의 105 °C/125 °C 등급(주문 코드 접미사 7/3) 실제 존재 여부와 패키지.
3. STM32G0B1, STM32G431, TI MSPM0G3507과 비교해 원가·고온·RS-485 하드웨어 DE·플래시 구조·장기 공급 측면의 장단점.
4. FPU 없는 코어로 1 Hz ppm 계산과 5계수 모델을 처리할 때의 실제 부담.
5. 이 요구사항에서 놓친 MCU 관련 위험(ESD, 클럭 정확도와 Modbus 보레이트, 플래시 내구성, 부트로더 안전성 등).
답은 표 하나와 추천 1순위·2순위로 정리하고, 확신이 낮은 사실은 "확인 필요"로 표시할 것.
```
