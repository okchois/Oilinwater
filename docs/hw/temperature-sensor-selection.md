# 온도 센서 선정 — IST AG 소형 RTD (Pt1000)

작성일: 2026-09-29 · 조건: **Pt1000 선호** (두텍) · 자료: IST 제품 페이지 요약 (검색 결과. ist-ag.com은 이 환경에서 직접 열리지 않음)

## 1. 요구 조건

| 항목 | 요구 | 근거 |
|---|---|---|
| 소자 | Pt1000 (IEC 60751) | 두텍 선호. 리드 저항 영향이 Pt100의 1/10 |
| 정확도 | ±0.1 °C 수준 (교정 후) | 60 °C에서 1 °C 오차 → ppm 약 3 % 오차 |
| 온도 범위 | −40 ~ +120 °C (오일) | 설계 목표 |
| 크기 | 캐리어 9.5 × 4.5 mm 위에 습도 센서(MK33-W mini 5.0 × 3.81)와 함께 | 기구 Rev C, [습도 센서 선정](humidity-sensor-selection.md) |
| 응답 | 습도 센서와 같은 온도를 빨리 따라갈 것 | aw → ppm 환산은 센서 표면 온도 기준 |

등급 허용차 (IEC 60751): F0.1 = ±(0.1 + 0.0017·|t|) °C → 20 °C에서 ±0.13 °C, 100 °C에서 ±0.27 °C. F0.15 = ±(0.15 + 0.002·|t|) °C → 20 °C에서 ±0.19 °C.

## 3. 선정

### **MiniSens Pt1000 class F0.1 (1.6 × 1.2 mm, 선 10 mm)**

- **Pt1000이고 가장 작은 리드선형 중 하나입니다.** 1.6 × 1.2 mm라서 캐리어에 MK33-W mini(5.0 mm)와 나란히 놓아도 약 7.6 mm로 캐리어(9.5 mm) 안에 들어갑니다.
- **습도 센서 바로 옆에서 빠르게 반응합니다.** aw → ppm 환산은 습도 센서 표면 온도를 써야 하므로, 작고 가까운 소자가 유리합니다.
- **F0.1 등급이라 교정 부담이 작습니다.** 1점(또는 2점) 교정으로 ±0.1 °C 목표에 맞출 수 있습니다. 원가를 줄여야 하면 같은 크기의 F0.15로 바꾸고 교정으로 보완합니다.
- 온도 범위(−200 ~ +600 °C)가 오일 120 °C에 충분합니다. 리드선 재질·길이는 캐리어 용접·납땜 방식에 맞춰 IST에 지정합니다.

## 4. 결선 — HTX99R 4핀 커넥터와의 관계

HTX99R 커넥터(4핀)를 쓰면 습도 2핀 + Pt1000 2핀이라 **Pt1000이 2선식**이 됩니다.

- Pt1000은 0.1 Ω 리드 저항이 약 0.026 °C 오차에 불과합니다 (Pt100이면 0.26 °C). 프로브 안 배선(수 cm)과 커넥터 접촉 저항을 합쳐도 **교정으로 오프셋을 없애면 0.05 °C 이하**입니다.
- 그래서 Pt1000을 쓰면 **2선식으로 충분합니다.** Pt1000을 선호하신 것이 이 구조에 잘 맞습니다.
- 회로 변경: ADS1220 결선을 4선식 → **2선식 비율 측정**(IDAC 1개, 기준저항 4.02 kΩ 0.01 % 유지)으로 바꿉니다. 커넥터 접촉 저항의 온도·경년 변화는 초기 시험에서 확인합니다.
- **반영 (결정 #16, 회로도 v0.4):** J3(JST SH 4핀) 핀 3 = PT_P, 핀 4 = PT_N. 힘선(IDAC → AIN0)과 감지선(AIN1/AIN2)은 **J3 패드에서 나눠** PCB 배선 저항은 빠지고, 하네스·HTX99R·프로브 리드 저항(합계 약 0.3–0.5 Ω → 약 0.1 °C)만 남습니다. 이 값은 교정 오프셋으로 제거합니다.

## 5. 확인 요청

1. 캐리어 재질·접합 방식 (세라믹 + 용접 / PCB + 납땜) → 리드선 재질·길이 지정, 또는 SMD 0805로 변경 여부
2. F0.1 / F0.15 단가 (IST 견적) — 교정 공정과 비교해 결정
3. HTX99R 4핀 배정 확정 시 ADS1220 2선식 회로로 변경 (회로도 다음 개정)
