# HMT500(ED260313A) A5-R3 — 정식 명칭·전체 로고

## 바뀐 것

사용자가 중간 번호 0313을 확인하여 PCB 정식 명칭을 **HMT500(ED260313A)**로 통일했다. 현재 프로젝트 폴더, `.kicad_pro/.kicad_pcb/.kicad_sch`, 하위 시트, 회로도 표제, PCB 실크와 신규 Gerber/BOM/CPL 파일명을 변경했다. 이전 릴리스는 과거 기록으로 보존하며, 심볼/풋프린트 라이브러리 별칭 `HMT500_260313A`는 기존 연결 호환성을 위해 유지한다.

탑면에 **DOTECH + SENSING & CONTROL 전체 로고**를 원본 비율로 배치했다. 폭 11.5 mm, 높이 3.203 mm. PCB 명칭과 A5-R3 표시는 그 아래에 둔다.

## KiCad에서 편집

- 레퍼런스: 각 부품의 실제 `Reference` 필드이다. KiCad에서 위치·크기·방향·표시 여부를 편집할 수 있다.
- PCB 명칭: 실제 F.SilkS `PCB_TEXT`이다. 이미지나 PDF 덧글이 아니다.
- 로고: 실제 F.SilkS 채움 다각형 21개를 `DOTECH full logo` 그룹으로 묶었다. 그룹으로 이동하거나 그룹 해제 후 개별 도형을 편집할 수 있다. PNG를 기판에 삽입한 것이 아니다.
- 편집용 묶음은 프로젝트와 전용 라이브러리를 함께 포함한다. 압축 해제 후 `HMT500(ED260313A)/HMT500(ED260313A).kicad_pro`를 연다.

## 검사

전체 재생성 및 테스트 33개 통과. 넷리스트 81/81 일치, DRC 오류 0, 미연결 0. 이전 PCB와 배선·비아·패드 형상/넷 및 부품 위치/면/회전은 동일하다. 저장된 보드를 다시 읽어 네이티브 레퍼런스 110개, 전체 로고 그룹 1개/다각형 21개, 정식 명칭 텍스트 1개를 확인했다.

## 남은 위험

실크 레퍼런스 92개 표시, 18개 미표시 상태를 유지한다. 높이 0.6 mm를 적용한 22개는 인쇄성 확인이 필요하다. DRC 경고는 작은 문자 22개와 기존 라이브러리 차이 2개이며 오류가 아니다. 로고 부제의 작은 세부 형상도 제조사 실크 인쇄성 검토 대상이다. 기존 제조 DFM·온도·몰딩·EMC 조건은 유지한다.

미표시: D51, U13, U15, U2, C28, C4, C44, C45, C48, C50, C55, FB1, R14, R19, R31, R51, R52, R9.

이번 변경은 명칭/실크 수정이며 발주 승인이 아니다.
