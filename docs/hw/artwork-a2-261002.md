# HMT500 PCB A2 작업 결과 — 2026-10-02

**미완성 초안 · 제작/주문 금지.** 직접 재배치와 배선을 진행했지만 제작 가능한 완성본까지 도달하지 못했다. 현재 4층 A2의 DRC 일반 오류는 **0건**, 미연결은 **33건**이다. A1은 미연결 32건이었다. 중요 아날로그 경로를 개선한 것과 전체 배선을 완료한 것은 구분해야 한다. 완료율을 백분율로 제시하지 않는다.

## 바뀐 것

- 회로 v0.10, 기구 Rev I 외형, 두께 1.6 mm, 4층을 유지했다. 부품 110개. 입력 12–28 V, VAO 16.1 V, RL≤500 Ω(전원≥18 V), TPS26611과 AO TVS1401 및 RS-485 TVS3301 조건을 바꾸지 않았다.
- `placement/artwork_A2.json`을 배치 생성기 입력으로 추가했다. 기구 간섭·높이·코트야드·하네스 공간은 기존 생성기 제약으로 검사한다. J1/J3/J5/J2와 MCU 위치는 유지하고 주변 전원·측정·AO 부품을 재배치했다.
- CREF, 벅 SW/FB, DAC CMP 배선 길이를 줄였다. 아래는 해당 넷의 전체 배선 길이를 합한 값이며 두 핀 사이 최단 길이 또는 EMI 성능을 뜻하지 않는다.
- CHASSIS 전용 경로를 연결했다. CHASSIS 간격 1.0 mm/선폭 0.5 mm, RTN–GND 간격 0.30 mm 조건을 유지했다. RTN 전용 구리와 내층 GND 제외 영역을 유지한다.
- DAC PowerPAD GND 방열 비아 12개를 추가했다. 반대면 솔더마스크 텐팅을 지정했다. 비아 충전·캡핑을 지정한 것은 아니며 납 흡수 및 열 성능은 제조사/시제품 확인이 필요하다.
- 일부 디지털 비아는 패드 0.40 mm / 드릴 0.20 mm이다. 일반 관통 비아이며 HDI 구조는 아니다. JLCPCB에서 작은 비아 패드는 추가 비용 대상이므로 최종 DFM/견적 확인이 필요하다.
- A1 스냅샷을 보존했고 A2는 배치 원본 + 배선 스냅샷으로 다시 생성할 수 있다. 배치가 다르면 복원을 거부한다. 거버·제작 주문 ZIP은 발행하지 않았다.

`lib_footprint_mismatch` 2건은 C44/D1의 실크 외곽을 Fab로 옮긴 차이이다. `via_dangling`·`track_dangling`은 미완성 인출부 등 정리가 필요한 동박이며 경고를 숨기거나 제외 처리하지 않았다.

KiCad 자체 회로도 비교에서 계층 넷 별칭 및 J2 BOM 플래그 차이가 기존에 확인됐다. 원본 생성기의 실제 패드–넷 분할 대조와 별개이므로 **네이티브 회로도 비교 오류 0이라고 보고하지 않는다.**

## 남은 위험

1. MCU·DAC·ADC 주변의 양면 패드와 관통 비아가 남은 배선 경로를 막는다. 현재 배치의 일부 경로를 반복해서 걷어내는 방법은 다른 연결을 다시 끊는 결과도 냈다. 이 초안을 그대로 계속 자동배선하면 완료된다고 보장할 수 없다.
2. 접지, 전원, 측정 입력, 통신/제어 중 아래 미연결 항목을 모두 해소해야 한다. 입력 보호 제어가 미연결 목록에 있으면 보호 기능도 성립하지 않는다. 전원을 인가할 보드가 아니다.
3. 모든 연결을 마친 뒤 전원·서지 경로의 선폭/병목, GND 연속성과 리턴 경로, 핀 주변 디커플링 루프, 방열 면적, 제조 공차를 다시 검토해야 한다. 현재 DRC 일반 오류 0만으로 이 검토를 대신할 수 없다. A2에서도 OUT1_P 전체 배선 48.26 mm, VAO 83.99 mm 등 우회 경로가 남아 있다(분기 합계이며 핀 사이 최단 길이는 아님). 짧아진 국부 경로만으로 전체 배선 품질이 확보됐다고 판단하지 않는다.
4. 몰딩 발열·서지/역극성·정확도 시험, 제품 온도 사양, L2/L3 포화 전류 정의, JLC 미확정 2줄 및 BOM/CPL 회전 확인은 여전히 남는다.
5. 별도 6층 비교안은 DRC 일반 오류 0 / 미연결 23건이었다. 층을 늘려도 핀 인출 문제는 남았다. 실제 제조 스택업과 전체 배선이 검증된 대안이 아니므로 **채택하지 않았고 이 저장소/전달 묶음의 A2는 4층이다.** 4층 제작이 불가능하다는 결론도 내리지 않았다.

## 내가 결정할 것

이번 결과를 근거로 6층 변경이나 주문 승인을 요청하지 않는다. 현재 확정 조건을 유지했다. 미연결 0, 일반 DRC 오류 0, 전원/측정 경로 검토를 만족하는 구체적인 안이 마련되기 전에는 제작 단계로 넘어갈 수 없다. 기존 제품 온도·몰딩 재료 등의 미결 사항은 결정 기록을 따른다.

## 재현 및 파일

- `hardware/kicad/rebuild_artwork.sh`: 기본 A2. `HMT_ARTWORK=A1`이면 A1 재현. `KICAD_PYTHON`, `KICAD_CLI`, `TEST_PYTHON`으로 환경 지정. KiCad Python에 openpyxl이 필요하다.
- `hardware/kicad/routing/artwork_A2_draft.json`: 최종 보존한 A2 배선 초안. 실험 라우터 결과를 최종 검사 없이 복사하지 말 것.
- `hardware/kicad/HMT500(260313A)/HMT500(260313A)_artwork_drc.json`, `artwork_check.json`: 검사 원문.
- `hardware/mech/out/assembly_sim/report.json`: 기구 검사 원문.
- 재생성 스크립트 종료 코드 0은 초안 재현/검사 실행 성공이며 제작 승인이 아니다. 마지막 미연결 수를 반드시 확인한다.
- 제조사 PDF는 저장소와 전달 묶음에 추가하지 않았다. 제조 한계 참고: [JLCPCB 공식 PCB capabilities](https://jlcpcb.com/capabilities/pcb-capabilities/).
