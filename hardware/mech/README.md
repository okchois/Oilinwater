# HMT500 기구 설계 (Rev A)

DOTECH HMT500 오일 수분 트랜스미터의 3D CAD와 2D 제작 도면입니다. 모든 치수는 `hmt500_params.py` 한 곳에서 관리하고, 여기서 3D 모델과 도면을 함께 생성합니다.

![HMT500 렌더](out/HMT500_render.png)
![HMT500 단면 렌더](out/HMT500_render_section.png)

## 산출물 (`out/`)

| 파일 | 내용 |
|---|---|
| `HMT500_mechanical_drawings.pdf` | **제작 도면 3장 (A3)**: 조립도 M-000(부품표·주기), 바디 M-101, 보호캡·하우징·엔드캡 M-102~104 |
| `HMT500-M-000_assembly.svg` 등 | 도면 원본 SVG |
| `HMT500_assembly.step` | 3D 조립품 (구매품 단순 형상 포함, 색 구분) |
| `HMT500-M-101_body.step` ~ `M-104_endcap.step` | 가공 부품별 3D (가공 업체 견적용) |
| `HMT500_render*.png` | 외관 / 절단 렌더 |

## 주요 치수

| 항목 | 값 |
|---|---|
| 전장 | 142 mm (프로브 끝 ~ 커넥터 끝) |
| 노출 프로브 / 공정 나사 | 34 mm, Ø12 / G1/2-A ISO 228-1, 14 mm |
| 육각 / 하우징 | AF27 / Ø30 × 60 |
| 씰면 기준 | 하우징 끝 79 mm, 커넥터 끝 94 mm |
| 가공품 질량 (316L) | 바디 119 g, 캡 8 g, 하우징 64 g, 엔드캡 31 g (합계 약 222 g, 전자부·커넥터 제외) |

## 구조 요약

1. **바디(M-101):** 보호캡 체결부(M10×0.75), Ø12 프로브, G1/2 나사, 언더컷, 육각 AF27, Ø30 용접 칼라, Ø27 h7 하우징 삽입부까지 한 덩어리로 선삭합니다.
   - 앞쪽 Ø8 H7에 유리-금속 피드스루(6핀)를 레이저 용접해 **압력 격벽**을 만듭니다.
2. **보호캡(M-102):** 나사 결합 교체형이며, 측면 Ø2.6 구멍 8개와 끝단 Ø3 구멍이 있습니다.
3. **하우징(M-103):** Ø30/Ø27 H7 튜브입니다. 바디와 엔드캡에 끼운 뒤 전둘레 레이저 용접합니다. 시제품은 나사+O링 결합으로 대신할 수 있습니다.
4. **엔드캡(M-104):** M16×1.5 구멍으로 M Connect 8핀 커넥터를 뒤쪽에서 장착합니다.
5. **전자부:** 원형 PCB Ø26 2장(측정 / 전원·출력), 스페이서로 간격을 유지합니다.

## 다시 만들기

```bash
python3 hardware/mech/hmt500_drawings.py && hardware/mech/make_pdf.sh   # 2D 도면 (추가 설치 불필요)
pip install cadquery                                                    # 3D는 CadQuery 필요
python hardware/mech/hmt500_cad.py                                      # STEP
python hardware/mech/render3d.py                                        # 렌더 (OSMesa/EGL 필요)
```

## 확인·확정이 필요한 항목

- **피드스루:** 규격(Ø8, 6핀, 헬륨 리크, 내압)을 공급사와 확정해야 합니다. 바디 안착부 치수가 여기에 따라 바뀝니다.
- **커넥터:** M Connect 품번(장착 나사 M16×1.5 가정, 돌출 길이, O링)을 확정해야 합니다.
- **센서 캐리어:** IST MK 센서 도면을 받아 캐리어 형상과 보호캡 내부 공간을 확정해야 합니다.
- **체결 토크:** 보호캡 체결 토크와 G1/2 설치 토크(본디드 씰 규격)를 정해야 합니다.
- **내압 검증:** 200 bar형의 내압 검토(FEA)가 필요하고, 지금 도면은 50 bar 정격 기준입니다.
- **나사 표현:** 3D의 나사는 원통으로만 표현했습니다. 나사 규격은 2D 도면의 표기를 따릅니다.
