# DOTECH 전체 실크 로고

사용자 작업 폴더 `Claude/OILWATCH/docs/assets/dotech_logo_navy.png`에서 가져온 두텍 원본.
DOTECH와 SENSING & CONTROL 부제를 함께 사용한다.
`generate_dotech_wordmark.py`는 전체 알파 윤곽을 추출한다(Pillow, numpy, shapely 2.1).
`dotech_wordmark.json`의 외곽/구멍을 KiCad 네이티브 채움 다각형으로 변환하고, `DOTECH full logo` 그룹으로 묶는다. KiCad에서 그룹 이동, 그룹 해제 후 도형 편집이 가능하다. PNG를 PCB에 붙인 것이 아니다.
